### The Objective
I am building a web dashboard for crafters. When they checkout, they click a button that opens a native UPI app (GPay/PhonePe) via a web intent, auto-filling the Merchant Name, UPI ID, and exact Amount (e.g., ₹299.00).

### The Current Implementation
I dynamically fetch a base string from a `/upi.txt` file (currently: `upi://pay?pa=nihalmavungal0@oksbi&pn=Tro Gifts&cu=INR`).
In React, I am constructing the deep link and QR code like this:

```javascript
// NewOrder.jsx snippet
<a
    href={encodeURI(`${upiBaseUrl}&am=${Number(price).toFixed(2)}`)}
    className="..."
>
    Open UPI App to Pay
</a>
```

### The Exact Problem & Symptoms
The deep link DOES successfully open Google Pay and PhonePe. It accurately auto-fills the name ("Tro Gifts") and the exact amount ("₹299.00").

However, when I attempt to complete the payment:
1. **Google Pay Error:** Immediately throws the error: *"You exceeded the bank limit for this payment, retry with smaller amount."* (Even on small test amounts like 299, well within my actual SBI bank limits).
2. **PhonePe "Gallery Scan" Error:** If I download the QR code image and scan it from the PhonePe gallery, it throws: *"You can pay up to ₹2000 rupees with QR code via gallery... for more pay with mobile number or scan any QR code."*
3. **The Weird Exception:** I tested the *exact same deep link intent* using a different linked bank account on my phone, and it processed perfectly without limits!

### What We Have Already Tried (And Failed)
